# InvestigationManager v0.36.1

## 사용자 조작성
- 전체 데이터시트 열 설정의 드래그 조작성 개선.
- 오른쪽 ↕ 손잡이의 터치 영역 확대.
- 손잡이를 길게 눌러 선택이 확정되면 해당 행 전체를 하이라이트하고 선택됨 표시.
- 선택된 상태에서 손가락을 떼지 않고 한 번의 드래그로 여러 칸을 연속 이동.
- 한 칸 이동마다 드래그가 끊기지 않도록 드래그 세션 유지.
- 편집 저장 중 뒤로 가기를 막고, 저장하지 않은 변경사항은 이탈 전 확인.
- 설정 화면 하단에서 설치된 앱 버전/versionCode 확인.

## 데이터 및 상태 안정성
- 신규/진행중/의뢰취소/완료 상태 규칙을 공통 로직으로 통합.
- 이미 완료된 건에서 완료를 다시 선택해도 기존 완료시각 유지.
- 지도에서도 공통 상태 정규화 규칙 사용.
- 신규 OCR 등록 중 원본 저장 실패 시 반쪽 등록이 남지 않도록 생성 데이터 롤백.
- 카메라 원본 이동 후 등록 실패 시 잘못된 재시도를 막고 다시 촬영하도록 안내.
- 월별 CSV 내보내기에 실제 선택 주소 추가.
- 데이터시트 인쇄 문구를 실제 표시 열 기준으로 수정.

## 복귀 및 화면 흐름
- 조사일정/데이터시트에서 편집 후 조사일정 복귀 시 해당 조사건 자동 스크롤·강조.
- 편집 중 조사건이 삭제된 경우 남아 있던 강조 대상 상태 정리.
- 상태별 색상을 조사일정, 편집화면, 데이터시트, 캘린더에 일관되게 적용.
