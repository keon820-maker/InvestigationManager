# v0.35.32

- 조사의뢰서 화면과 PDF에 조사예정일 칸을 추가했습니다. 저장된 예정일을 표시하며 날짜가 없으면 미지정으로 표시합니다.
- 채무자 이름을 사람 이름 길이로 제한해 법인명이 잘리던 문제를 수정했습니다. 법인명 전체와 원문에 있는 마스킹된 식별번호를 유지합니다.
- 줄바꿈된 법인 임차인 이름과 괄호 안에 반복된 전화번호를 같은 표 칸에서 읽습니다. 이름 인식이 실패해도 확인된 임차인 전화번호는 편집 화면에서 검토할 수 있도록 유지합니다.
- 도로명 안의 숫자와 길·번길 사이에 잘못 생긴 공백을 정리하고 건물·동·호수 숫자는 그대로 유지합니다.
- 표 인식 후에도 기타요청사항 아래의 영업점·의뢰자·전화·팩스를 별도로 검사하고, 부족한 경우 해당 영역을 확대해 재인식합니다. 금융센터 등 지점 이외의 영업점 명칭도 유지합니다.
- 서로 다른 이름이나 번호가 충돌하면 검토 대상으로 남깁니다. 조사담당자 연락처를 영업점 연락처로 가져오지 않습니다.

검증에는 가상 법인명·전화번호로 만든 합성 문서만 사용합니다. 사용자 원본 및 개인정보는 저장소나 CI에 포함하지 않습니다. 기존에 저장된 잘린 이름은 자동으로 추정해 변경하지 않으므로 원본을 대조해 편집할 수 있습니다.
