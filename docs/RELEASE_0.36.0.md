# InvestigationManager v0.36.0

## 사용자 기능
- 조사일정 필터를 기본 접힘 상태로 변경하고 현재 날짜/진행상황/보기방식을 한 줄로 요약.
- 조사일정 날짜별/조사번호 보기 전환.
- 신규/진행중/의뢰취소/완료 상태를 화면 전반에서 색상으로 구분.
- 편집화면 상단 두 번째 줄에서 현재 진행상황 확인 및 즉시 변경.
- 조사일정 또는 전체 데이터시트에서 편집 후 복귀 시 해당 조사건으로 자동 스크롤하고 잠시 강조.
- 전체 데이터시트 상태별 건수 표시.
- 전체 데이터시트 행 1회 선택, 같은 행 재탭 시 편집 진입.
- 전체 데이터시트 열 표시/숨김 및 길게 눌러 드래그 순서 변경.
- 전체 데이터시트에 선택 주소와 주소 유형 표시.
- 첨부파일 삭제 버튼과 원본 보기 클릭영역 분리, 삭제 진행/오류 상태 표시.
- 저장되지 않은 편집 내용이 있을 때 뒤로 가기 경고.

## 데이터 및 로직
- 진행상황 변경 규칙을 공통 로직으로 통합.
- 의뢰취소 상태가 전체 데이터시트에서 신규로 변환되던 문제 수정.
- 기간 조회 시 기존 지연 필터가 남아 있던 문제 수정.
- 월별 CSV 내보내기에 선택 주소 추가.
- 조사건 휴지통 삭제 시 첨부 원본 보존 정책 유지.

## QA / 배포
- main 최신 커밋에도 Galaxy Tab형 Android 16 에뮬레이터 테스트 자동 실행.
- 기존 GitHub Release APK를 같은 버전으로 덮어쓰지 않도록 변경.
- 사용자 배포 변경 시 versionName/versionCode 동시 증가.
- 상태/데이터시트/주소/정렬/인쇄/OCR 회귀 테스트 유지 및 보강.
