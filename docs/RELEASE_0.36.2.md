# InvestigationManager v0.36.2

## 사용자 기능 및 조작성
- 전체 데이터시트 열 설정에서 ↕ 손잡이를 길게 눌러 선택 시 행 전체 하이라이트 및 선택 상태 표시.
- 선택된 열을 손가락을 떼지 않고 여러 칸 한 번에 이동 가능.
- 데이터시트 행 선택은 화면 재진입 시 초기화되어 항상 1회 선택 → 같은 행 재탭 편집 규칙 유지.
- 키보드가 열린 상태에서도 상세화면 저장바가 키보드 위에 유지.
- 저장 중 뒤로가기를 누르면 저장 완료 후 자동으로 복귀하도록 처리.
- 조사일정/데이터시트 편집 후 원래 조사건 자동 스크롤·강조 안정화.

## 데이터 및 로직 안정성
- 신규/진행중/의뢰취소/완료 상태 규칙 공통화.
- 완료 상태 재선택 시 기존 완료시각 유지.
- 일정의 상태/예정일 빠른 변경은 최신 DB 행을 다시 읽어 다른 기기의 최신 필드 덮어쓰기 방지.
- 신규 OCR 등록 중 원본 저장 실패 시 반쪽 등록 롤백.
- 클라우드 첨부파일 삭제 시 원격 파일/메타데이터 정합성 강화.
- Android 9 이상에서 월별 ZIP 검증이 정상 동작하도록 API 호환성 수정.
- 첨부 미리보기 상태 처리 Lint 오류 수정.
- 월별 CSV에 실제 선택 주소 포함.
