# v0.35.33

## 조사 일정 조회

- 앱을 열면 조사 일정의 기본 조회일이 현재일로 설정됩니다.
- 달력 버튼을 눌러 시작일과 종료일을 지정할 수 있습니다.
- 상단의 `오늘`, `내일`, `이번주`, `미지정`, `지연` 버튼으로 해당 일정만 바로 조회할 수 있습니다.

## 캘린더

- 캘린더 아래의 일정을 누르면 `편집` 또는 `길찾기`를 선택할 수 있습니다.

## 동선 기능 제거

- 일정의 동선 버튼, 방문순서 편집, 거리순 자동정렬, 동선순 정렬을 제거했습니다.
- 일정 카드와 지도 마커에 표시되던 방문순서 번호를 제거했습니다.

## 태블릿 회전 안정화

- 가로·세로 회전 시 액티비티가 호환성 창으로 다시 열리지 않도록 창 크기 변경을 앱 내부에서 처리합니다.
