# v0.35.34

## 편집 화면

- 우측 상단 `조사의뢰서` 옆에 `길안내` 버튼을 추가하고 선택한 지도 표시 주소로 연결했습니다.
- `이 조사건 삭제` 버튼을 작은 버튼으로 변경하고 삭제 전 확인창을 유지·강화했습니다.
- 각 첨부파일에 `삭제` 버튼과 확인창을 추가했습니다.
- `조사확인서 첨부`를 `기타 자료 첨부`로 변경했습니다.
- 갤러리 또는 카메라로 기타 자료를 추가하기 전에 자료 이름을 입력할 수 있습니다.

## 캘린더

- 일정 카드에 물건소재지만 고정 표시하지 않고, 편집 화면에서 선택한 지도 표시 주소와 주소 유형을 표시합니다.

## 조사 일정

- `전체보기`, `오늘`, `진행중`, `지연`, `의뢰취소`, `완료` 버튼으로 일정을 필터링할 수 있습니다.
- 각 일정의 `⋯` 메뉴에 `의뢰취소`를 추가했습니다. 의뢰취소는 조사건을 삭제하지 않고 별도 상태로 보관합니다.
