# v0.34.0 최적화 기록

기능과 기존 데이터 형식을 유지하면서 반복 연산, 메인 스레드 파일 작업, 동기화 쿼리 수, 이미지 메모리 점유와 APK 크기를 줄였다.

## 적용 내용

- OCR 입력 이미지를 한 번만 디코딩·정렬하고 모든 인식 및 보정 단계에서 재사용
- 정렬·회전·미리보기·지도 마커 Bitmap의 수명 종료 시 메모리 회수
- 갤러리 원본 복사, 카메라 원본 확정, 연도별 ZIP 내보내기를 IO 디스패처에서 실행
- 카메라 임시 파일은 같은 저장소에서 이름 변경을 우선 사용해 불필요한 전체 복사 방지
- ZIP 생성과 SHA-256 계산을 한 번의 파일 읽기로 통합하고 이미 압축된 이미지에 빠른 ZIP 압축 사용
- 클라우드 ID 보정과 동기화 완료 표시를 Room 트랜잭션으로 묶고 N+1 조회 제거
- 조사건 Firestore 업로드를 400건 단위 배치 쓰기로 변경
- 첨부 메타데이터 비교를 메모리 색인으로 처리하고 변경 없는 행의 DB 갱신과 매번 수행하던 전체 파일 해시 재계산 제거
- 실제 배포 단말용 ARM ABI와 한국어·영어 리소스만 APK에 포함
- Gradle 빌드 캐시와 병렬 실행 활성화
- Compose 화면에서 반복 JSON 파싱과 불필요한 제스처/동선 상태 재생성 방지

## 보존한 안전 조건

- 원본 증거 파일은 리사이즈하거나 재압축하지 않음
- 새 첨부 업로드 전과 다운로드 후 SHA-256 전체 검증 수행
- 기존 Room 스키마와 마이그레이션, Firebase UID별 데이터 경로, 휴지통 동기화 정책 유지
- 기존 영구 서명 설정과 Kakao/Firebase 비밀값 주입 방식 유지

## 지원 범위

배포 APK는 `arm64-v8a`와 `armeabi-v7a` Android 실기기를 지원한다. x86/x86_64 에뮬레이터에는 이 APK를 설치할 수 없으며, 에뮬레이터가 필요하면 개발용 ABI 설정을 별도로 사용해야 한다.
