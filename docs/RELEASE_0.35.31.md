# v0.35.31

- 신규 등록 화면에서 OCR 처리 단계와 버전 문자열을 기본적으로 숨기고 짧은 결과만 표시합니다. 자세한 기록은 '인식 진단 보기'에서 확인할 수 있습니다.
- 실제 OCR 입력과 진단 기록을 분리해 후속 보정이 처리 기록을 다시 문서 내용으로 읽지 않도록 했습니다. 기타요청사항의 반복 제목과 중복 문장을 정리하며 서로 다른 요청과 금액은 유지합니다.
- 이미 저장한 기타요청사항은 편집 화면의 '중복 문구 정리'로 확인 후 저장할 수 있습니다. 기존 데이터는 일괄 변경하지 않습니다.
- 문서 사진의 글자 방향을 기기에서 확인해 회전한 뒤 OCR합니다. 원본 보기에도 방향 보정을 적용하며 원본 파일 바이트는 변경하지 않습니다.
- 편집 화면 상단에서 조사 예정일을 선택하거나 미지정으로 변경할 수 있습니다. '변경 저장'을 누르면 반영됩니다.
- 조사 일정에서 날짜별로 조사번호(관리번호)와 등록일자의 오름차순·내림차순 정렬을 선택할 수 있습니다. 정렬 선택은 화면 회전 후에도 유지됩니다.

검증에는 합성 데이터만 사용합니다. 실제 문서 및 개인정보는 저장소나 CI에 포함하지 않습니다.
